## 🚀 Product Overview

NextHire is a modern, responsive, web-first global talent platform engineered to connect candidates, recruiters, and enterprise companies through intelligent skill-first matching, verified employer profiles, and automated ATS recruitment workflows.

---

## 🛠️ Technology Stack & Architecture

- **Web Core:** Next.js 14 App Router, React 18, TypeScript, TailwindCSS
- **Database & Data Layer:** PostgreSQL database, Prisma ORM (v5.22.0)
- **Security & Authentication:** Cryptographic scrypt password hashing, database-backed `Session` token management, HttpOnly cookies, server-side RBAC & multi-tenant UUID company isolation
- **Search Infrastructure:** Search Provider Abstraction Layer (`NextHire DB`, `Google Custom Search`, `Bing Web Search`, `Brave Search`, `Licensed Partner Feeds`) with parallel aggregator, 3s timeout resiliency, deduplication engine, and AI natural-language query parser
- **SEO & Metadata:** Schema.org `JobPosting` JSON-LD structured data, dynamic `sitemap.xml`, `robots.txt` privacy route disallow rules
