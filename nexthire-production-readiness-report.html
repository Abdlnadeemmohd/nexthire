Method Endpoint RBAC Permission Purpose & Execution
POST /api/auth/login Public Verifies scrypt password hash or preconfigured developer profile; issues HttpOnly cookie.
POST /api/auth/firebase Public Server-side Firebase Admin ID token verification; provisions PostgreSQL user & issues session.
GET /api/jobs Public Queries filtered active jobs from PostgreSQL database or search provider fallback.
POST /api/jobs RECRUITER / ADMIN Creates new job listing tied to recruiter's multi-tenant company ID.
GET /api/recruiter/jobs RECRUITER / ADMIN Fetches jobs scoped strictly to recruiter's authenticated company UUID.
POST /api/recruiter/applicants/[id]/status RECRUITER / ADMIN Validates state machine transition, updates status, fires notification, and logs audit record.
GET /api/search Public Parallel multi-engine search aggregator (NextHire, Google, Bing, Brave) with 3s timeout & dedup.
GET /api/documents/download Authenticated Issues 15-minute presigned document download token for authorized candidates and recruiters.
GET /api/admin/audit PLATFORM_ADMIN Fetches chronological audit logs for platform security compliance.
